# Cheetavah Socks Website

A responsive static storefront prototype for Cheetavah Socks.

## GitHub Pages setup

1. Create a new GitHub repository, for example: `cheetavah-socks`
2. Upload ALL files and folders from this project:
   - `index.html`
   - `style.css`
   - `script.js`
   - `assets/`
3. Open the repository on GitHub.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
6. Click **Save**.
7. GitHub will show the public website URL after deployment.

## Important

The cart and newsletter are front-end demos only. They do not process real payments or store customer data.

For real ecommerce checkout, connect the website to Shopify, Stripe, PayPal, Snipcart, or another ecommerce backend.
